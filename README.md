## 🚀 Featured Capstone: Posture-AI (CVA Matrix)

**[Live Web Application: Posture AI](https://aryanstudys21-a11y.github.io/posture-ai/)** | **[Repository](#)**

A real-time, interactive clinical tool designed to automate the measurement of the **Cervical Vertebral Angle (CVA)** for objective Forward Head Posture (FHP) tracking.
- **Clinical Application:** Translates biomechanical markers (C7 spinous process and tragus) into a programmatic coordinate system, mitigating inter-rater reliability issues found in traditional manual goniometry.
- **Technical Architecture:** Engineered utilizing Python, MediaPipe pose estimation, and OpenCV, deployed alongside an interactive SVG skeletal overlay to provide instantaneous quantitative feedback.
